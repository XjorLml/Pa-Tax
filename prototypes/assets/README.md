The symbol combines a ledger with a speech corner: professional experience and direct conversation. It is not a verification badge. The lowercase wordmark is drawn rather than typeset. Use the full logo at 155 CSS px or wider and the icon at 24 CSS px or larger; the favicon is simplified for 16 px. Keep clear space of one quarter of the icon's width. Preserve proportions and avoid shadows, outlines or unapproved color changes.

Standalone logos have accessible titles. In an HTML header with the adjacent name, use `alt=""` on the icon to avoid announcing the name twice. Pair light assets with light surfaces, dark assets with dark surfaces.
