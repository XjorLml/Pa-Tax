# Kuwenta identity assets

Original code-native vector artwork created by the agent for this repository on 2026-11-11 under the user's delegated branding brief. No third-party artwork, icons, downloaded fonts or traced logos were used. The wordmark consists of original geometric paths; the SVGs contain no font dependency. Source-code licensing remains PRD D16; no separate third-party asset licence applies. Name/domain clearance has not been performed.

| Asset | Use |
|---|---|
| [Light logo](kuwenta-logo-light.svg) | Full identity on white or warm paper |
| [Dark logo](kuwenta-logo-dark.svg) | Full identity on dark forest surfaces |
| [Icon](kuwenta-icon.svg), [dark icon](kuwenta-icon-dark.svg) | Header, sign-in, compact branding |
| [Favicon](favicon.svg) | Simplified 32-unit browser icon |

The symbol combines a ledger with a speech corner: professional experience and direct conversation. It is not a verification badge. The lowercase wordmark is drawn rather than typeset. Use the full logo at 140 CSS px or wider and the icon at 24 CSS px or larger; the favicon is simplified for 16 px. Keep clear space of one quarter of the icon's width. Preserve proportions and avoid shadows, outlines or unapproved color changes.

Standalone logos have accessible titles. In an HTML header with the adjacent name, use `alt=""` on the icon to avoid announcing the name twice. Pair light assets with light surfaces, dark assets with dark surfaces. [DESIGN](../../docs/DESIGN.md) owns the palette and UI identity; these files are reusable in the future Blazor `wwwroot` directory.
